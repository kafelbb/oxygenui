## типы данных
oxygenui добавляет кастомные типы данных, такие как:
- **vector4** (и его аналог vec4)
- **color** 
- **color_composition**
- axis
- layout
- text_align_x (и его каунтерпарт text_align_y)
- **mousebutton**
- **event_t**
- **event** 
<br>
_ __
**vector4** - аналог  UDim2 из Roblox Studio.<br> 
используется в **size** и **pos**.<br>
является математическим вектором, который хранит в себе:
 - float **x_scale** - нормализированная относительная **X**  координата
 - float **x_offset** - абсолютная **X**  координата
 - float **y_scale** - нормализированная относительная **Y**  координата
 - float **y_offset** - абсолютная **Y**  координата

 > под нормализированной координатой подразумевается дробное число от 0 до 1 (и > 1, просто как проценты поделенные на 100)
 _ __
**vec4** - аналог **vector4**, который используется исключительно во внутренних функах библиотеки.
является математическим вектором, который хранит в себе:
- float **x** - нормализированная относительную **X**  координату
- float **y** - нормализированная относительную **Y**  координату
- float **z** - нормализированная относительную **Z**  координату
- float **w** - нормализированная относительную **W**  координату
_ __
**color** - тип данных, описывающий цвет и его позицию в линейном градиенте.
<br>хранит в себе:
- sf::Color **content** - трех/четырехчисловой мат. вектор, описывающий цвет по RGB(A)
- float **position** - дробное число, обозначающее позицию цвета в линейном градиенте.
_ __
**color_composition** - массив данных из **color**, который и определяет цвет объекта.
<br>хранит в себе:
- std::vector<std::shared_ptr<color>> **content** - массив из **color**.
_ __
**axis** - enum class, обозначающий ось для рассчетов
<br>может обозначать:
 - width (по умолчанию) - ширину
 - height - высоту
_ __
**layout** - enum class, обозначающий способ позиционирования и расчета размеров детей **объекта**
<br>может обозначать:
 - none (по умолчанию) - дети позиционируются независимо друг от друга
 - flex_x - дети заполняют свободное пространство по оси **X**.
 - flex_y - дети заполняют свободное пространство по оси **Y**.
_ __
**text_align_x** - enum class, обозначающий то, к какой стороне объекта будет прилегать текст по оси **X**
<br>может обозначать:
 - center (по умолчанию) - центр
 - right - право
 - left - левр
_ __
**text_align_Y** - enum class, обозначающий то, к какой стороне объекта будет прилегать текст по оси **Y**
<br>может обозначать:
 - center (по умолчанию) - центр
 - top - верх
 - bottom - низ
_ __
**mousebutton** - enum class, обозначающий кнопку мышки
<br>может обозначать:
 - left - левую кнопку
 - right - правую кнопку
 - middle - среднюю кнопку
 - none - никакую кнопку
_ __
**event_t** - enum class, обозначающий тип события, произошедчего с объектом
<br>может обозначать:
 - none - ничего
 - mouseup - отпускание кнопки мыши на объекте
 - mousedown - зажатие кнопки мыши на объекте
 - hover - наведение курсора мышки на объект
 - scrollup **(не имплементированно)** - скролл колесиком мышки вверх, когда курсор находится над объектом
 - scrolldown **(не имплементированно)** - скролл колесиком мышки вниз, когда курсор находится над объектом
 _ __
 **event** - структура, позволяющая удобно отслеживать события связанные с тем или иным объектом
 <br>в себе хранит:
  - event_t **type** - тип события
 - mousebutton **button** - нажатая кнопка (правая / левая / средняя)
 - sf::Vector2f **mouse_pos** - позиция мышки
 - uiobject* **object** - ссылка на объект, с которым и произошло это событие
 _ __
 ## архетиктура
 ### графический конвеер
 переменные **графического конвеера**:
 - const float **pi** - число пи, используемое для скругления углов
 - bool **updating** - флаг, говорящий конвееру пересчитать абсолютные размеры объектов, пересоздать ``render_texture`` этих объектов и перерисовать их в новые рендер-текстуры
 - std::vector<std::shared_ptr<uiobject>> **ui_objects** - массив, хранящий все когда-либо созданные объекты
 
<br>методы **графического конвеера**:
 - void **draw(sf::RenderTarget& win)** - начинает рисовать корневые объекты, и запускает отрисовку их детей
 - void **sort()** - сортирует объекты в ``ui_obejcts`` по их ``global_z_index``
 - event **check_events(sf::Event& ev, sf::RenderWindow& win)** - проверяет случилось ли какое-то событие и возвращает объект ``event``
 ### uiobject
 **uiobject** (далее просто объект) - это класс, который и является тем самым неоднократно упомянутым, абстрактным **объектом**, из инстансов которого и строится весь GUI.
 <br>вместо кучи классов по типу **Frame**, **ImageLabel**, **TextLabel** и других из Roblox Studio,<br>
 и вместо кучи тэгов по типу **div**, **img**, **p** и других из HTML/CSS, у нас есть **один** класс, который является репрезентацией всех выше перечисленных.
<br><br>именно такое строение обусловлено особенностями синтаксиса C++ и, конечно же, моей ленью.
<br><br>
внутри каждого объекта хранится его **sf::Sprite** и **sf::RenderTexture**. если вы не знакомы с SFML, то **рендер-текстура** это грубо говоря такой же холст как и **sf::Texture**, который можно загружать в спрайты. Только в **sf::Texture**
рисовать другие спрайты нельзя, а в **RenderTexture** можно.
<br>Так вот, **oxygenui** устроен так, что объект рисуется сначала в свой **RenderTexture**,
потом эта текстура идет в спрайт объекта, и этот спрайт рисуется в **RenderTexture** родителя. Да, при таком строении ребенок не может выйти за
границы родителя, но зато вашему ПК не нужно каждый божий кадр тратиться на рендер **OpenGL** шейдеров, градиенты и подобное.
<br>Ведь если объект был отрисован в **RenderTexture** и не был после этого изменен, то и тратить циклы
ЦПУ на расчет геометрии и силы ГПУ на отрисовку шейдеров не нужно. Объект уже есть в памяти как массив пикселей,
которые нужно просто вывести на экран.
<br><br>Проще говоря, **uiobject** - это контейнер, хранящий в себе уже отрисованного себя и своих детей. Ну и свои свойства конечно же.

свойства (property) **uiobject**:
* основные
	* bool **clickable** (по умолчанию ``true``) — определяет, будет ли объект учитываться при обработке кликов в ``get_events()``
	* vector4 **size** — размер объекта относительно его родителя
	* vector4 **pos** — позиция объекта относительно его родителя
	* float **visibility** (по умолчанию `1.0f`) — видимость (прозрачность) объекта. расчитывается относительно видимости родителя.
	* float **roundness** — коэф. скругления углов объекта
	* color_composition **background_color** — цвет заливки объекта
	* color_composition **border_color** — цвет обводки
	* float **border_size** — толщина обводки объекта
	* float **padding** — отступ объекта от границ его родителя
	* int **rotation** — угол поворота объекта в градусах
	* int **id** — числовой айди объекта
	* int **z_index** (по умолчанию `0`) — z-index относительно своего родителя
	* int **global_z_index** (по умолчанию `0`) — глобальный z-index. (to be deprecated)
	* std::string **name** — имя объекта

* **системные свойства**
	* sf::Vector2f **real_size** — абсолютный размер объекта в пикселях
	* sf::Vector2f **real_pos** — абсолютная позиция объекта в пикселях относительно **своего родителя**
	* sf::Vector2f **absolute_pos** — абсолютная позиция объекта относительно **окна приложения**
	* sf::Image **img** — сырые данные background_image
	* sf::Sprite **sprite** — спрайт объекта. при ``draw_obj()`` как раз таки он и рисуется в ``render_tex`` родителя
	* sf::RenderTexture **render_tex** — буфер, куда рисуется объект и его дети
	* sf::Sprite **image_sprite** — спрайт background_image
	* sf::Font **font** — объект шрифта

* **тени**
	* float **shadow_size** — радиус размытия тени
	* sf::Vector2f **shadow_offset** — оффсет тени по **X** и **Y**
	* sf::Color **shadow_color** — цвет тени

* **лэйаут**
  * layout **layout_type** (по умолчанию `layout::none`) — способ позиционирования детей объекта внутри него и рассчета их размеров
  * sf::Vector2f **flex_padding** — зазор между детьми объекта. при layout\::none не учитывается

* **текстурирование**
	* sf::Texture **background_image** — текстура загруженного изображения
	* std::string **image_path** — путь к файлу background_image на диске
	* bool **repeated** — флаг, включающий повтор текстуры
	* sf::Vector2f **image_offset** — смещение изображения
	* sf::Vector2f **image_scale** — масштаб изображения

* **ограничения**
	* float **aspect_ratio** (по умолчанию `0.0f`) — ограничение соотношения сторон объекта
	* axis **dominant_axis** (по умолчанию `axis::width`) — ось, которая будет привелигирована при расчете размера объекта с учетом ``aspect_ratio``
	* float **min_w** / float **min_h** (по умолчанию `0.0f`) — минимальные размеры осей в пикселях
	* axis **dominant_padding_axis** (по умолчанию `axis::width`) — ось, по которой вычисляется отступ в пикселях

* **текст**
	* std::string **text_content** (по умолчанию пустой) — текст, который будет нарисован в ``render_texture`` объекта
	* sf::Color **text_color** — цвет текста
	* sf::Color **text_border_color** — цвет обводки текста
	* float **text_border_size** — толщина обводки текста
	* sf::Text::Style **text_style** — стиль начертания
	* std::string **font_path** — путь к файлу шрифта
	* float **text_size** (по умолчанию `1.0f`) — размер шрифта относительно ``dominant_axis``
	* text_align_x / text_align_y — выравнивание текста по той, или иной стороне объекта
	* bool **text_wrap** (по умолчанию `false`) — флаг, включающий автоперенос строки

* **связи**
	* uiobject* **parent** — указатель на родительский объект
	* std::vector\<uiobject*\> **children** — массив из указателей на детей объекта

<br>методы (функции класса) **uiobject**:
 - static std\::shared_ptr<uiobject> **create()** - создает объект класса **uiobject** и добавляет его в глобальный массив объектов std::vector **ui_objects**
 - void **add(uiobject * child)** - добавляет в объект ребенка
 - void **sort()** - сортирует список детей объекта по z-index
 - void **set_image(std\::string s, bool smooth = true)** - загружает изображение в ``background_image``

 ## примеры использования
 вместо того, чтобы много душниить сухой теорией, просто покажу несколько примеров использования библиотеки
 ### пример 1
 самое простое приложение, которое себе можно представить
#### **uithing.h**
 ```cpp
#include "oxygenui-lib/oxygenui.h"

void init_ui() {
	auto thing = uiobject::create(); //создаем объект
	thing->pos = { 0, 0, 0, 0 };
	thing->size = { 1, 0, 1, 0 }; //thing занимает 100% ширины и 100% высоты родителя (в нашем случае окна)
	thing->roundness = 0.1; //thing имеет закругление в 10% от ширины окна
	thing->padding = 0.1; //и имеет отступ в 10% dominant_padding_axis (в нашем случае 10% от ширины экрана)

	auto white = std::make_shared<color>(); //создаем объект цвета раз
	white->content = sf::Color(255, 255, 255);
	white->position = 0.0f;

	auto gray = std::make_shared<color>(); //создаем объект цвета два
	gray->content = sf::Color(70, 70, 70);
	gray->position = 1.0f; //ставим позицию серого цвета в самый конец градиента

	thing->background_color.content.push_back(white); //добавляем цвета в массив background_color
	thing->background_color.content.push_back(gray);

	sort(); //сортируем всех по глобальному z-index (здесь это кнш необязательно)
}
```
#### **main.cpp**
```cpp
#include <iostream>
#include <chrono>

#include "oxygenui-lib/oxygenui.h"
#include "uithing.h"

void update(sf::RenderWindow& win) {
    win.clear({ 1,0,0 }); //ИМЕННО 1,0,0 , по какой-то причине с включенным antialiasing при заливке 0,0,0 все окно становится черным
    draw(win);
    win.display();
}

void start(sf::RenderWindow& win) {
    sf::Event ev;

    update(win); //я без понятия почему, но при первом запуске нужно именно два раза вызывать апдейт
    update(win);

    while (win.isOpen()) {
		//если происходят какие-либо анимации на фоне или еще что-то, что требует постоянного обновления окна, то юзайте while(win.pollEvent(ev)) !
        if (win.waitEvent(ev)) { //ждем SFML-событий (именно sfml, НЕ тех, что относятсся к oxygenui!!!!11111)
            if (ev.type == sf::Event::Closed) {
                win.close();
            }
            if (ev.type == sf::Event::Resized) {
                sf::FloatRect visibleArea(0.f, 0.f, static_cast<float>(ev.size.width), static_cast<float>(ev.size.height));
                win.setView(sf::View(visibleArea));
                update(win);
            }
        }
    }

    ui_objects.clear(); //очищаем список объектов, чтобы вовремя удалить объекты OpenGL и не словить краш
}


int main() {
    sf::ContextSettings st; //настраиваем контекст OpenGL так, чтобы у нас был 8x antialiasing (сглаживание)
    st.antialiasingLevel = 8;
    sf::RenderWindow win;
    win.create(sf::VideoMode(512, 512), "example1", sf::Style::Default, st); //здесь мы создаем объект окна

    win.setVerticalSyncEnabled(true);

    init_ui(); //функция, которую мы объявили в uithing.h
    start(win);

    return 0;
}
```
